# Block 3 skills: start here

Seven skills, in the order of today's slides.

1. /vcodebook: write the coding rules
2. /vclassify: apply your codebook to the texts
3. /vcoder-agreement: compare the machine labels with your hand codes
4. /vcalibrate: correct a rate with your hand-coded sample
5. /vdiscover: find topics without a codebook
6. /vdescriptives: counts and shares
7. /vtable-format: format tables

## Install

Copy each folder (for example vcodebook/) to your skills folder, then restart the agent.

- Antigravity: `.agents/skills/` in your workspace, or `~/.gemini/config/skills/`
- Claude Code: `~/.claude/skills/`

Then type the skill name, for example /vcodebook, in your project folder.
